# 🖋️ Fonts, Text & Syntax Highlighting Practice

A clean and minimalist web page demonstrating CSS typography properties and the integration of third-party syntax highlighting libraries.

## 🚀 Live Demo
Check out the live version here:https://devhacker-soni.github.io/CSS-Fonts-Practice/

## 🧠 What’s Inside?
This project focuses on the visual presentation of text and code. Key features include:
- **Custom Typography**: Integrated 'Poppins' from Google Fonts for a modern look.
- **CSS Text Properties**: Implementation of `text-transform`, `text-decoration`, `line-height`, and `text-align`.
- **Syntax Highlighting**: Used **Prism.js** to display CSS code blocks beautifully within the browser.
- **Semantic HTML**: Proper use of `<article>`, `<main>`, and `<footer>` tags for better accessibility.

## 🛠️ Technologies Used
- **HTML**: Semantic structure.
- **CSS**: Custom styling with a signature `#CD5C5C` (Indian Red) theme.
- **Prism.js**: For professional-grade code formatting.
- **Google Fonts API**: For high-quality web fonts.
